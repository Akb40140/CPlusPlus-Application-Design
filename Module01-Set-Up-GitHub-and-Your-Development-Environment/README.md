# Module 1 - Set Up GitHub & Your Development Environment

## Assignment
Create a public GitHub repository named something like C++-Application-Design or
Teach-Cpp-YourName. Inside the repository, create a folder for every module. Put your
Module 1 work in the first assignment folder, add a README, and verify that another
person can open the repository without signing in.

## What I did
- Made a public repo called `CPlusPlus-Application-Design` with a README.
- Made a folder for each of the 15 modules.
- Installed g++ and tested it with `hello_world.cpp`, which prints a message.
- Opened the repo in an incognito window to make sure it works without signing in.

## Terms
- **Repository** - the whole project on GitHub (this class)
- **Folder** - one module's work inside the repo
- **File** - a single file like `hello_world.cpp`
- **Commit** - saving a snapshot of my changes with a message
- **Push** - sending my commits from my computer up to GitHub

## How to run
```
g++ -o hello hello_world.cpp
./hello
```

## Output
```
My C++ application is ready!
```
