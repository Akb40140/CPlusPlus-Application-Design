# Module 11 - Showcase Your Application

## Assignment
Create a 6-10 slide presentation. Include the problem, target user, application features,
screenshots, data flow, a short "How to Use It" guide, challenges, and future
improvements.

## My presentation
`Student-Record-Manager-Showcase.pptx` has 9 slides. You can open it in PowerPoint, or
upload it to Google Slides (File > Import slides) or Canva (Create a design > Import
file). Each slide has speaker notes with what I say.

| Slide | What's on it |
|-------|--------------|
| 1 | Title: Student Record Manager |
| 2 | The problem and target user (teachers as Admins, helpers as Regular Users) |
| 3 | Key features: menu, roles, binary search, sorted records, validation, AI Study Coach |
| 4 | How the data flows, from `students.csv` to the screen |
| 5 | Screenshots: login/menu and viewing students |
| 6 | How to use it (build, run, log in, pick options), with a validation screenshot |
| 7 | C++ features I used and the module each came from |
| 8 | Challenges and lessons learned |
| 9 | Future features, then thank you and questions |
