## About my application
The Student Record Manager keeps track of students and their math scores. It loads
students from a CSV file (from a Kaggle dataset), lets an Admin add, update and delete
students, and lets a Regular User view and search. It checks all input, finds students
with binary search, and has a mock AI Study Coach that gives study tips. Each module
added a new part to it.
